# ZORU token logo

Official ZORU token logo assets for wallets, block explorers, and token lists.

| File | Resolution | Purpose |
| --- | --- | --- |
| `zoru-logo.png` | 1254 × 1254 | Original master PNG, transparent background |
| `zoru-logo-512.png` | 512 × 512 | Standard wallet and explorer icon |
| `zoru-logo-256.png` | 256 × 256 | Smaller UI and token-list icon |

These are raster PNG assets. The master file is preserved unchanged; the smaller sizes are resized derivatives.

Raw URL for the master:

`https://raw.githubusercontent.com/zoruco/zoruco/main/assets/token/zoru-logo.png`

For integrations that require immutable resources, pin this asset to a specific commit rather than the `main` branch.
